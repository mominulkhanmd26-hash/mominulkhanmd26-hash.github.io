HOW TO USE
1. Open index.html in your browser.
2. Put your own images in the images folder using these names:
   profile.png, about.png, project1.jpg, project2.jpg, project3.jpg
3. Put your CV in assets/cv.pdf
4. Replace # links for GitHub, LinkedIn, project live demo and project GitHub.
5. The contact form currently shows a demo message. Connect Formspree or a backend to receive submissions.
